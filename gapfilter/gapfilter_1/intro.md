对基因进行了Min-max归一化处理，预测的spot之间的差分值，效果和KNN接近，下面给出了分析结果。

对照你的 HBC 结果：Top PCC≈0.78，和 KNN Top（0.78）几乎持平，说明模型大体在「邻居插值」附近打转，没有明显超出。限制点主要在下面这些（按影响大致从大到小）。

1. 训练目标与推理目标不对齐（最关键）
训练：只在 train–train 上拟合 f(x1,x2)≈y2−y1
推理：用 train→test，y_test ≈ y_train + f(x_train, x_test)
网络从未直接学过「从邻居绝对表达推出 test 绝对表达」，绝对水平几乎全靠邻居的 y_train；f 一旦偏小，就会塌成邻居均值，效果接近 KNN。
2. 含自身的配对稀释梯度信号
n_neighbors 含自身 → 大量 (i,i)，目标 Δy=0
模型容易学会「特征相近就输出接近 0」
推理时 train/test 特征若相似，Δy≈0，再次退化成邻居平均。
3. 五折是按 pair 划分，不是按 spot
同一 spot 可同时出现在 train/val 的不同 pair 里 → 验证泄漏
val/loss 偏乐观，选到的 checkpoint 对真实 gap test 不一定好。
4. 推理聚合弱于 KNN baseline
你这边对邻居是 等权平均
KNN baseline 用的是 weights='distance'
gap 里远近邻居混在一起时，等权更容易被噪声邻居拖累。
5. 只学相对量，误差会叠在邻居上
最终预测 = 邻居表达 + 预测差分
邻居选错或跨 gap，差分网络很难「纠正」绝对水平
这是方法设定本身的上限，不只是超参问题。
6. 逐基因 min-max 的副作用
min/max 由 train 极值决定，多数基因被压得很窄
反归一化后，归一化空间里的小误差会被放大
预测还可能超出 [min,max]，和真实分布更容易错位。
7. 特征与网络表达能力
输入是 3072 维 local∥contextual 直接拼接，未见标准化
普通 concat MLP 很难稳定学反对称梯度；antisym 损失还可能把输出往 0 推
现在若改成 general_svg（上千基因多输出），容量压力更大。
8. 评估会「看起来更怪」
只训练 Top 基因时，General 未预测基因被填成 train 均值 → PCC 被跳过恒定基因，和 Top 撞车；RMSE 仍不同
这会干扰你对「泛化差」的判断，但不解释 Top 本身为什么没明显超过 KNN。
一句话：当前管线本质上是「空间邻居基线 + 学一个易塌缩的差分修正」；训练又几乎没见过 train→test / 跨 gap 配对，所以预测容易停在 KNN 附近。若要抬效果，优先改的是：训练配对分布（含跨 gap/伪 test）、弱化或去掉自身对、按 spot 做 CV、推理改距离加权，并考虑加绝对表达监督，而不是先堆更深 MLP。
